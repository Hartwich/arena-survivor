# Frostfire Survival artwork — 2026-09-14

Generated with the built-in OpenAI image-generation tool for this game. No external stock imagery was used. Original output alpha is preserved for all props. The source PNGs live under `public/host/arena-survivor/themes/frostfire-saga/survival/`; the existing game sync pipeline publishes them to the host.

The playable world uses a simple ground texture repeated every 512 world units over an open 4800 × 3600 field. Twelve render chunks share one continuous texture coordinate system. Only the separately placed rock/crystal sprites have physical collision; ground texture details are traversable. Projectiles fly over low obstacles. The initial road-based painting was discarded after the user's clarification and is not shipped or loaded. Objective positions are freely sampled on clear ground. Rock footprints and safe fallback positions live in `src/survivalWorld.ts`.

Visual direction reference: [Vampire Survivors on Steam](https://store.steampowered.com/app/1794680/Vampire_Survivors/). No graphics from that game were copied.
